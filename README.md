# 🍏 CHIPS Store — Premium Apple Device Showcase

A modern and elegant e-commerce showcase focused on premium Apple devices, crafted with a minimalist aesthetic and smooth interactive experiences.  
CHIPS Store delivers a high-performance browsing experience with bilingual support, animated shopping drawers, advanced product filtering, and responsive layouts optimized for both desktop and mobile devices.

---

# ✨ Features

## 🌐 Real-Time Bilingual Switcher (EN / ID)
Instantly switch the entire interface between **English** and **Indonesian** without page reloads.  
All product labels, categories, buttons, and descriptions update dynamically.

## 💻 Premium MacBook & iPhone Catalog
Carefully curated showcase of high-end Apple products including:

- MacBook Air
- MacBook Pro
- iPhone Series
- Premium Accessories

Every product card includes high-quality imagery with optimized rendering and responsive layouts.

## 🔍 Advanced Multi-Level Filtering
Interactive filtering system with real-time updates:

- Product category tabs
- Brand filters
- Device family filters
- Specific iPhone generation grouping
- Smooth visual transitions during filtering

## 🛒 Animated Shopping Cart & Wishlist Drawers
Beautiful slide-out side panels powered by **Framer Motion** featuring:

- Quantity adjustment
- Remove single items
- Clear all items
- Wishlist management
- Smooth motion physics & transitions

## 🖼️ High-Quality Media Experience
Premium product photography sourced from high-resolution assets for a polished and professional visual experience.

## 📍 Store Outlets & Contact Form
Interactive retail outlet section combined with a responsive customer feedback form featuring validation and clean UI states.

## 📱 Fully Responsive Design
Optimized for:

- Desktop
- Tablet
- Mobile devices

Layouts adapt seamlessly across all screen sizes.

# 🛠️ Tech Stack

| Technology | Description |
| :--- | :--- |
| **React 18** | Modern component-based UI library |
| **TypeScript** | Strong static typing for better scalability and maintainability |
| **Tailwind CSS** | Utility-first CSS framework for fast and responsive styling |
| **Framer Motion** | Smooth animations and interactive transitions |

| **Vite** | Lightning-fast frontend build tool |

# 🚀 Getting Started

## 📋 Prerequisites

Make sure you have installed:

- Node.js (v18 or newer)
- npm or yarn

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/chips-store.git
```

Navigate into the project directory:

```bash
cd chips-store
```

Install dependencies:

```bash
npm install
```

---

# ▶️ Run Development Server

```bash
npm run dev
```

Open your browser at:

```bash
http://localhost:3000
```

---

# 📦 Production Build

Generate an optimized production build:

```bash
npm run build
```

Preview production build locally:

```bash
npm run preview
```
